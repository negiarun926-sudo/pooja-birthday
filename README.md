# Pooja Birthday Surprise ❤️

A cinematic Next.js birthday website for Pooja.

## Local setup

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Photos

The included photos are:

- `public/images/pooja-1.jpg`
- `public/images/pooja-2.jpg`

Replace them with your own files if needed.

## Music

Put your own licensed/owned song here:

`public/music/romantic-song.mp3`

The site starts the music after the birthday unlock/user interaction because mobile browsers can block autoplay.

## Unlock

The surprise unlocks at:

**23 September 2026, 10:00 AM IST**

Change `UNLOCK_AT` in `app/page.tsx` if you want a different date/time.
